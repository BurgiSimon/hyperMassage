# Massage Claudia Bürgi — three websites

Three complete, independent website concepts for the massage practice of **Claudia Bürgi** in Kestenholz (SO).
Same business, same goal — immersive and award-worthy, but built to bring in appointments. Each folder is a
self-contained static site (Vite); pick one and deploy its `dist/`.

| | Site | Idea |
| --- | --- | --- |
| 1 | [`sites/1-lass-los`](sites/1-lass-los) | **«Lass los.»** — night, warmth and breath. Hot stones rendered live in WebGL that glow when you touch them. |
| 2 | `sites/2-entspannung` | *in progress* |
| 3 | `sites/3-ein-tag` | *in progress* |

```bash
cd sites/<site>
npm install
npm run dev       # local dev server
npm run build     # static build → dist/
```
